# 舆见 macOS 使用说明

## 最快查看：网页演示版

解压后直接双击 **`网页演示版.html`**，用 Safari 打开即可看到内置 45 条评论的分析结果。

这是静态演示，不能提交新视频，也不能导出文件，但足以展示产品界面、情感分布、方面分析、风险、主题、回复和选题建议。

## 完整交互：源码版

### 1. 安装 Python 3

macOS 不一定自带 Python 3。请先安装：

https://www.python.org/downloads/macos/

安装完成后，终端输入 `python3 --version` 应能看到版本号。

### 2. 启动

双击 **`启动舆见.command`**。

如果系统提示“无法打开，因为来自身份不明的开发者”：

1. 右键点击 `启动舆见.command`；
2. 选择“打开”；
3. 在弹窗中再次点击“打开”。

如果仍然被拦截，进入：

`系统设置 → 隐私与安全性 → 仍要打开`

### 3. 使用

启动后浏览器会自动打开：

`http://127.0.0.1:7860`

首次演示可直接勾选 **“使用演示数据（无需 Cookie、无需 Key）”**，点开始即可完成全流程。

完整交互版支持：

- 粘贴 B 站视频、动态、BV/av 号
- 采集公开评论
- 情感与方面分析
- 风险、主题、回复、选题
- CSV / Markdown 导出

## 配置大模型

编辑同目录下的 `config.json`：

```json
{
  "base": "https://openai.cuc.edu.cn/v1/chat/completions",
  "model": "cuc/deepseek",
  "key": "你的 API Key"
}
```

不填 Key 时自动使用规则分析，仍可完成演示。

## 真实采集 B 站评论

在页面中粘贴视频链接或 BV 号即可。未登录 Cookie 时通常只能获取少量评论；如需更多评论，可在页面填入自己浏览器的 B 站 Cookie。

Cookie 与 API Key 只保存在本机，不会上传。

## 常见问题

**双击后终端一闪而过？**

右键 → 打开，或在终端中执行：

```bash
chmod +x 启动舆见.command
./启动舆见.command
```

**提示端口被占用？**

程序会自动尝试 7861 等后续端口，以终端输出的地址为准。

**没有网络或没有 API Key？**

勾选演示数据，或直接使用 `网页演示版.html`。
