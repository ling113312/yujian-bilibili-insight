# 测试说明

## 冒烟测试

```bash
python tests/smoke_test.py
```

脚本会：

1. 选择空闲端口启动 `app.py`；
2. 请求 `/api/health`；
3. 以 `demo=1&engine=rule` 调用 `/analyze`；
4. 检查结果页是否包含"正面、中性、负面"；
5. 关闭临时服务。

成功输出：`SMOKE_OK port=xxxxx`。

## 已执行验收

| 用例 | 输入 | 结果 |
|---|---|---|
| 真实采集 | `BV1YQ4i6tEJv`，3 页，含楼中楼 | 279 条，对账成立 |
| LLM 分析 | 239 条批次 | 约 82.9 秒 |
| 情感对账 | 279 条 | 正 + 中 + 负 = 279 |
| 无 Cookie | 未登录采集 | 约 3 条并提示可见范围 |
| LLM 失败 | 无效 Key 或 429 | 规则降级并标注 |
| 端口冲突 | 7860 被占用 | 自动切换 7861 |
| 演示模式 | 断网、无 Key | 规则 10.9 秒，LLM 18.3 秒 |
