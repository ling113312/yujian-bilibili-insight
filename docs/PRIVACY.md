# 合规与隐私说明

## 数据范围

- 只处理公开视频、公开动态与公开评论。
- 不采集私信、手机号、住址等个人信息。
- 不绕过登录、验证码、付费墙或访问控制。

## 本地存储

- Cookie 与 API Key 只保存在本地内存或用户自己的 `config.json`。
- 不写入日志，不打包进 exe 或压缩包。
- 评论与对账记录保存在本地 SQLite `yujian.db`。
- 删除 `yujian.db` 即可清空历史数据，程序下次启动会重新建库。

## 展示与脱敏

- 页面展示作者标识时做脱敏处理。
- 不建立用户画像，不跨视频追踪个人。
- 导出文件由用户主动触发，默认保存在本地。

## 使用边界

- 采集默认限速，避免对平台造成压力。
- 课程演示与公开提交前，应确认所用视频和评论不涉及敏感个人信息或未公开内容。
- 本项目不用于商业舆情监测、账号追踪或任何侵犯他人隐私的用途。
