# 舆见 · 创作者评论区舆情洞察助手（交付版）

一个可在本机运行的 Web 产品：抓取 B 站评论 → 清洗去重对账 → 大模型方面级情感分析 → 负面预警/回复话术 → 对话追问 → 导出报告。

---

## 一、两种运行方式

- **方式 A（推荐，免安装）**：直接双击 **`舆见.exe`**。不需要安装 Python。
- **方式 B（源码运行）**：安装 Python 3.8+，双击 **`启动.bat`**。

两种方式都会自动打开浏览器并访问 `http://127.0.0.1:7860`；**关闭黑色窗口即停止服务**。

> 首次运行 exe 若弹出 Windows SmartScreen / 杀毒软件提示，选择“更多信息 → 仍要运行”或“允许”。这是 PyInstaller 打包程序的常见误报。

## 二、快速开始（30 秒，无需登录）

1. 双击 **`舆见.exe`**（或 `启动.bat`）。
2. 浏览器自动打开 `http://127.0.0.1:7860`（没打开就手动输入）。
3. 勾选 **“使用内置示例数据（无需 Cookie）”**。
4. 点 **“开始抓取并分析”**。
5. 查看看板：对账、情感环形图、方面分布、风险、吐槽主题、回复话术、负面 Top、全部评论，并可导出 CSV / Markdown。

## 三、抓取真实评论（需要 B 站 Cookie）

1. 在页面第一栏粘贴 **视频链接 / 动态链接 / BV 号**：
   - 视频：`https://www.bilibili.com/video/BVxxxx`
   - 动态：`https://t.bilibili.com/数字`（若是转发视频的动态，会自动解析到对应视频）
   - 也可直接填 `BV1xx411c7mD` 或 `av123456`
2. 获取 Cookie（Edge 浏览器，Windows 11）：
   - 登录 bilibili.com。
   - 按 `F12`（没反应用 `Fn+F12` 或 `Ctrl+Shift+I`；或右键 → 检查）。
   - 点 **网络 / Network** 标签（找不到就点标签栏右边的 `»`）。
   - 按 `F5` 刷新，点任意域名是 `api.bilibili.com` 的请求。
   - 右侧 **标头 / Headers → 请求标头 → Cookie**，复制整段。
   - 粘到页面的 **登录 Cookie** 框。
   - 备选：开发者工具 **应用程序 → 存储 → Cookie → https://www.bilibili.com**，复制 `SESSDATA`、`bili_jct`、`buvid3`、`DedeUserID` 拼成一行。
3. 设置抓取页数（每页约 20 条主评论，含楼中楼会更多），点 **开始抓取并分析**。
4. 等待 10–120 秒（条数越多越久）。

> 不带 Cookie 时 B 站匿名接口通常只放行 3 条主评论。提示 `code=-352/-412` 表示 Cookie 失效，重新复制即可。

## 四、接入大模型（可选，但推荐）

不配置 Key 时使用内置规则引擎，仍能跑通全流程；配置后逐条调用大模型判断“情感 + 强度 + 方面 + 理由”，结果更准。

三种配置方式，任选其一：

1. **页面填写（最简单）**：展开“大模型 API 设置”，填 API Key（Base / 模型默认已填好），点分析。
2. **修改 `config.json`**（必须与 `舆见.exe` 或 `app.py` 在同一目录）：
   ```json
   {
     "base": "https://openai.cuc.edu.cn/v1/chat/completions",
     "model": "cuc/deepseek",
     "key": "你的 API Key"
   }
   ```
3. **环境变量**：`LLM_BASE`、`LLM_MODEL`、`DEEPSEEK_API_KEY`。

默认适配学校代理（`https://openai.cuc.edu.cn/v1`，模型 `cuc/deepseek`）。若用其他 OpenAI 兼容服务，改 `base` 和 `model` 即可，例如：
- 硅基流动：`https://api.siliconflow.cn/v1/chat/completions`，`Qwen/Qwen2.5-7B-Instruct`
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`，`glm-4-flash`

> 若本机已安装并配置过 opencode，程序会自动读取 `~/.config/opencode/opencode.json` 里的 Key 和地址，无需再填。

## 五、功能清单

- 采集：B 站视频 / 动态 / BV / av；Cookie 登录；分页；楼中楼
- 清洗：去 HTML、去空白、去重、失败计数，**强制对账** `总量 = 入库 + 去重 + 失败`
- 分析：总体情感、方面级情感（内容质量 / 剪辑制作 / 价格付费 / 态度互动 / 广告推广 / 其他）、强度、理由
- 洞察：风险分级、核心吐槽主题、行动建议、下期选题、回复话术
- 对话：自然语言追问（大模型或规则）
- 导出：评论+分析 CSV、Markdown 报告
- 存储：本地 SQLite（`yujian.db`），数据不出本机

## 七、常见问题

- **exe 被 SmartScreen/杀毒拦截**：点“更多信息 → 仍要运行”或加入信任；这是 PyInstaller 单文件程序的常见误报。
- **双击 `启动.bat` 提示未检测到 Python**：安装 Python 并勾选 Add to PATH，或改用 `舆见.exe`。
- **端口被占用**：关闭之前启动的窗口；源码模式可先 `set PORT=7861` 再 `python app.py`。
- **抓不到评论**：Cookie 失效、评论区关闭、或触发风控；换新 Cookie，或先用示例数据演示。
- **大模型失败（401/403）**：Key 无效或无该模型权限；检查 Key、Base、模型名。
- **页面显示“规则兜底（未配置大模型 Key）”**：属正常，填 Key 后即为大模型结果。

## 八、隐私与合规

- Cookie / API Key 仅驻留内存（或你自行写入本地 `config.json`），不回显、不上传。
- 抓取仅用于课程学习与研究，请遵守 B 站用户协议，控制频率，不要用于商业用途或传播可识别的个人信息。
- 建议测试完成后在 B 站“账号安全”中退出所有设备，使 Cookie 失效。
